## I. 선행 연구 (Related Work)

본 연구의 위치 — 자동차 도메인에서 Kubernetes·컨테이너 오케스트레이션을 다룬 대표 선행 연구.
(발표 Slide 5 「관련 연구」)

### [1] Rehman et al., IEEE/SICE SII 2019
- **Title**: *A Cloud-based Development Environment using HLA and Kubernetes for the Co-simulation of a Corporate Electric Vehicle Fleet*
- **Authors**: K. Rehman et al.
- **Venue**: IEEE/SICE International Symposium on System Integration (SII), 2019, pp. 47–54
- **기여**: 자동차 도메인의 **분산 시뮬레이션 인프라**로 Kubernetes를 도입한 초기 사례. 클라우드 네이티브 스택이 자동차 개발 환경에 적용 가능함을 입증.
- **본 연구와의 관계**: K8s "적용 가능성"까지 다뤘으나 전환 구간 보안 문제는 미해결.
- **검색**: [IEEE Xplore — Rehman SII 2019](https://ieeexplore.ieee.org/search/searchresult.jsp?queryText=Rehman%20Cloud-based%20Kubernetes%20Electric%20Vehicle%20SII%202019)

### [2] Nayak, Grewe, Schildt, IEEE VNC 2023
- **Title**: *Automotive Container Orchestration: Requirements, Challenges and Open Directions*
- **Authors**: N. Nayak, D. Grewe, S. Schildt
- **Venue**: IEEE Vehicular Networking Conference (VNC), 2023, pp. 61–64
- **기여**: 자동차용 컨테이너 오케스트레이션의 **요구사항(실시간·안전·OTA)과 미해결 과제**를 정리한 포지션 논문.
- **본 연구와의 관계**: "전환 구간 보안"을 명시적인 미해결 과제로 지목 → 본 연구가 그 과제를 정량화·해결.
- **검색**: [IEEE Xplore — Nayak VNC 2023](https://ieeexplore.ieee.org/search/searchresult.jsp?queryText=Automotive%20Container%20Orchestration%20Requirements%20Challenges%20Nayak%20VNC%202023)

## II. 표준 및 레퍼런스 구현 — Uptane

본 연구의 4-서비스 추상화(auth/campaign/package/deploy)의 정당성 근거.
(발표 Slide 8 「위협 모델」 — Uptane CLI 매핑 병기)

### Uptane Standard
- [Uptane 공식 사이트](https://uptane.org/)
- [Uptane Standard for Design and Implementation (GitHub)](https://github.com/uptane/uptane-standard)
- [Uptane Deployment Best Practices (GitHub)](https://github.com/uptane/deployment-considerations)
- **핵심 인용**:
  - "OEM은 Director와 Image Repository를 설정·구성하며, 이 백엔드 서비스를 호스팅하기 위해 자체 인프라 또는 클라우드 컴퓨팅을 사용할 수 있다."
  - "Director는 특정 업데이트 캠페인에 대한 메타데이터에 서명해 차량에 특정 소프트웨어 번들을 설치하도록 지시하며, 여러 ECU에 걸친 소프트웨어 업데이트 조율이 포함된다."

### OTA Community Edition — Uptane 레퍼런스 구현
- [OTA Community Edition (GitHub Org — Advanced Telematic Systems)](https://github.com/advancedtelematic)
- [aktualizr — Uptane 클라이언트 레퍼런스 구현 (GitHub)](https://github.com/uptane/aktualizr)
- **실제 CLI 흐름 (본 연구의 4-서비스와 1:1 매핑)**:

  |---|---|
  | `auth` | `ota init` + `credentials.zip` (PKI 인증) |
  | `campaign` | `ota campaign create` |
  | `package` | `ota package add` |
  | `deploy` | `ota campaign launch` |

### 1. Tesla FSD (2023) — NHTSA 리콜 362,758대, OTA 긴급 패치

- **사건 요약**: Tesla Full Self-Driving Beta 소프트웨어 결함(교차로·정지 표지·황색 신호·속도 제한 처리 미흡)으로 2023-02-16 자발적 리콜 발표 → 2023-03-06부터 OTA 업데이트 배포.

### 2. BMW ConnectedDrive (2015) — ADAC 발견 SSL 취약점, 2.2M대 OTA 패치

- **사건 요약**: 독일 ADAC 연구진이 ConnectedDrive 통신이 SSL/TLS 미적용 HTTP XML로 평문 전송됨을 발견. 가짜 기지국으로 차량 원격 잠금 해제 가능. BMW가 HTTPS 강제 적용 패치를 약 2.2백만 대(BMW·Mini·Rolls-Royce, 2010-03 ~ 2014-12 생산)에 OTA 배포.

### 3. Jeep Cherokee (2015) — Uconnect 원격 해킹, 1.4M대 리콜 (Miller & Valasek)

- **사건 요약**: Charlie Miller·Chris Valasek이 Uconnect의 개방된 포트 6667을 통해 셀룰러 망 너머에서 차량의 조향·제동·변속·엔진을 원격 제어 시연(WIRED·Black Hat USA 2015). 같은 날 FCA가 1.4백만 대 리콜 → 사이버보안으로 인한 최초의 차량 리콜.
